# I hate it but it’s so useful — podcast posters

Season 1 promo for the Unnatural Intelligence podcast. The show name is the club line. Three episode posters, plus card versions of the same set.

Episode titles and the “upcoming” line are launch copy. There is no room booking and no published runtime on these sheets, so they are listen-promos, not a Saitsa event submission.

## Print

Open the HTML in Chrome. Print → Save as PDF. Margins none. Background graphics on.

- Posters: paper size **Tabloid / 11×17**
- Cards: paper size **Letter**

Or:

```bash
./Events/Podcast/capture.sh
```

That writes the PDFs, the screen previews, and the 300 DPI files under `png/` (`export_png.py`).

Palette, type, jellyfish, and the unaltered Saitsa Clubs logo match the vector kit and the other event posters. Contact is `unnaturalintelligencesait@gmail.com` and the current Discord invite.
