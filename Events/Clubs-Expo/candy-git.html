Booth staff · eyeball git · ~45 seconds

candy git — add, commit, push, pull

The candy is the file. The sticky is the commit message. The second bin is origin.

Say: “Git is save-points with a note. The second bin is the internet.”
CommandDo
git addGrab an eyeball from the starting container.
git commit -m "write comment"Write a comment on a sticky note and put it on the eyeball.
git pushPut the candy with the sticky note into the 2nd container.
git pullGrab somebody else’s eyeball with their commit note.

Good messages (8 words or fewer): fix lab 4 tone · ask about Thursday shift · cut the hope-this-finds-you

Staff

  • Starting bin stays full. Spare candy lives in a bag under the table.
  • Only pull a candy that already has a note. A bare eyeball is uncommitted — halt.
  • They keep the pulled candy. The one they pushed stays in origin for the next person.
  • If origin is empty at the start of the day, staff seeds three notes so the first visitor can pull.
