Candy git — the interactive

Inspired by the black pipeline booth. Two containers you already own. The candy is the file. The sticky is the message. The second bin is origin. About 45 seconds. No laptop required. Print the staff card: candy-git.html.

CommandWhat they do
git add Grab an eyeball from the starting container.
git commit -m "write comment" Write a comment on a sticky note and put it on the eyeball.
git push Put the candy with the sticky note into the 2nd container.
git pull Grab somebody else’s eyeball with their commit note.

Seed the second bin with three staff notes before doors open so the first visitor can pull. They keep the pulled candy. The one they pushed stays for the next person. Only pull a candy that already has a note.

Pipeline activity · ~60 seconds · no installgit walk — one commit, on paper

Teach one idea A commit is a snapshot + a message you wrote Skip GitHub accounts

Do not teach clone, rebase, or SSH at a fair. Teach one move: you pick what is allowed in, then you name the save-point in your own words. The monster binder is git log. The sticky note is the file. You are the remote.

Station map

Sign on the tableGit name (small, under it)What they do
01 INPUT working tree Write one line on a card, or pick a preprinted “AI slop” card.
02 HALT git add Cross out anything that sounds generic. Only the kept words may enter the repo.
03 HUMAN_FINISH git commit Rewrite the leftover into a message of 8 words or fewer that sounds like them. Staff stamps a 4-character “hash” and clips the card into the binder.
04 OUTPUT git push Sticker + QR. Say: “That’s shipping. You’re on main.”

Staff script (say this)

  1. “Git is save-points with a note. Walk the line.”
  2. INPUT: “One sentence you might actually send — or grab a bad AI card.”
  3. HALT: “git add is the choice. Cross out the robot voice.”
  4. COMMIT: “Message in eight words. If ChatGPT wrote it, we halt.”
  5. PUSH: Hand the sticker. “That’s the push. Binder is the log if you want to see yesterday’s commits.”

Preprint 3 “AI slop” cards

  • “I hope this email finds you well I wanted to reach out regarding…”
  • “In today’s rapidly evolving digital landscape, AI empowers students to…”
  • “Please find attached my comprehensive reflections on the assignment.”

Good commit examples to pin at station 03: fix lab 4 tone · ask about Thursday shift · cut the hope-this-finds-you

Concept 4 · ~$50 totalSpecimen Cabinet

Lime cloth + pink runner Stacked heights Guess-the-specimen

Quiet but sticky. Stack gift boxes or black cardboard as plinths so every prop sits at a different height, tagged like a museum: Jellyfish hat (genus: UI), Eyeball candy (plankton), Monster binder (field log). People stop to read labels. The interaction is “pick a specimen, we tell you the matching club idea” — hat = events, candy = low-token tips, binder = join, sticker = you leave with a piece of the collection.

Top-down

Label copy

  • JELLYFISH HAT — genus UI. Wear to become the mascot.
  • PAPER BALLOON — airborne token. Untapped potential: it floats until you use it.
  • EYEBALL CANDY — plankton. Small, frequent, slightly wrong.
  • MONSTER BINDER — field log. Sign here. Keep the human accountable.
  • STICKER — take a specimen home.

Best if your greeters like talking. Weak if the hall is too loud to read tags. Hang leftover paper balloons on fishing line from a rear dowel, not from the ceiling.
