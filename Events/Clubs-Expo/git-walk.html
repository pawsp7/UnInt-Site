Booth staff · Compile pipeline · ~60 seconds

git walk — one commit

Teach one idea: a commit is a snapshot plus a message they wrote. No install. No GitHub account. The four Compile Pipeline stations are the commands.

Say: “Git is save-points with a note. Walk the line.”
SignGitDo
01 INPUTworking treeOne line on a card, or pick an AI-slop card.
02 HALTgit addCross out the generic voice. Only kept words may enter.
03 HUMAN_FINISHgit commit8 words or fewer. Stamp a 4-char hash. Clip into the binder (git log).
04 OUTPUTgit pushSticker + QR. “That’s shipping. You’re on main.”

Do not teach clone, rebase, merge, SSH, or GitHub signup. If they ask “what is git?”: save-points with a note. If they ask “what is a commit?”: the snapshot you just named.
