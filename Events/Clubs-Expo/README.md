# Clubs Expo — 6 ft table concepts

Open **[table-concepts.html](table-concepts.html)** locally, or run `bash scripts/build-clubs-expo-site.sh` from the repo root and serve `docs/`.

**Recommended booth:** [Candy git](table-concepts.html#candy-git) — eyeball chews + two bins: `git add` → `git commit -m` → `git push` → `git pull`. Three layouts. Staff card: [candy-git.html](candy-git.html).

**Vercel:** root `vercel.json` builds this folder into `docs/` and publishes it. Import the GitHub repo at [vercel.com/new](https://vercel.com/new) (or claim a CLI deploy) to get a stable `*.vercel.app` URL.

**Programming builds** lean into a terminal / REPL look (lime on black, prompt labels, a laptop) while the 6×3 ft banner stays the entire table front.

**Compile pipeline activity:** a 60-second paper git tutorial. Print **[git-walk.html](git-walk.html)** (staff card, tent signs, AI-slop cards). Optional laptop seed is in **[git-walk-seed/](git-walk-seed/)**.

**Grand builds** are the louder balloon-arch / fringe versions if the hall needs spectacle more than a demo.
