Outlined fact bars

These SVGs are the same strip with the type converted to paths, so a print shop does not need the fonts. The transparent files have no background ink. A PNG with the same name sits beside every SVG in assets/. Inch-sized sheets are 300 DPI.

Tabloid borders

11×17 frames with a clear interior. Drop one over a poster. Strokes sit inside the trim.

Transparent grids

No background fill. The tiles repeat. The tabloid files are a half-inch alignment grid with a dashed 0.5 in safe margin. The split field behind each tile is only there so you can see the strokes.
