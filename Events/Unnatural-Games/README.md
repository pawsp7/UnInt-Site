## Edit before submission

Saitsa has not assigned a room, and approval covers one night. The sheets use the first Monday after Clubs Fall Showcase:

- **When:** Monday, October 19, 2026 · 6:00–8:00 PM
- **Where:** SAIT campus · room posted on Discord

Replace both lines with the booked date and room (for example `MB202 · Stan Grad Centre`) before [saitsa.com/Poster-Submission](https://saitsa.com/poster-submission/). The weekly series is not printed as a promise.

Search each HTML file for `Mon Oct 19` and `Room posted on Discord` (v2’s ticket says `Room on Discord`).

v4–v6 use the attached glitch name (`assets/name-glitch.png`), the full gradient jellyfish (not the mini mark), and `assets/glitch-bars.svg` with no background so the poster shows through.
